The funniest single line of wedding vows a robot couple could say — a promise with a double meaning. "Back you up" is emotional support *and* a nightly data backup, and the punchline lands in the last three words: even the corrupted files.

> I promise to back you up every night — even the corrupted files.

## Run it

```sh
python3 main.py
```

Writes the vow, exactly as-is with no trailing newline, to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to `/output`).
